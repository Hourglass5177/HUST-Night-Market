# 命名标准

# 脚本类名

**PascalCase，例如：**

GameManager\.cs

TurnManager\.cs

TileConfig\.cs

MarketRuntimeData\.cs

SettlementCalculator\.cs

# 变量名

**camelCase，例如：**

currentDay

currentMoney

studentRatio

temporaryTrafficBuff
