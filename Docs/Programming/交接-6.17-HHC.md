# HHC UI搭建说明
本文档用于给其他组员快速了解当前UI完成情况及约定。具体UI设计见飞书文档。
## 本次修改
完成S01和S02的所有UI场景搭建，仅布置了背景图和按钮排版，大部分脚本还未实现。S01中编写脚本`MainMenuManager`实现了简单的弹窗打开和关闭，S02实现了消息栏的信息发送。向消息栏发送信息的示例如下：
```text
public MessageScrollBar msgBar;

// 触发事件时添加普通消息
msgBar.AddNewMsg("今日夜市客流提升，收入增加！");
// 警告红色消息
msgBar.AddNewMsg("卫生检查不合格，罚款500！", true);
// 消息栏消息调用
```

主要修改的文件如下：
```text
Assets/_Project/Scripts/UI
Assets/Scenes
Assets/_Project/Prefabs/UI
```
UI画布中的数值仅作占位，具体显示数值由后续脚本确定。

## 说明
`PF_UI_Btn_stall`为夜市管理弹窗中左边列表的表项预制体，是一个按钮，点击不同的夜市按钮可以在右侧夜市管理界面显示对应夜市的摊位系统，否则各个摊位及夜市信息字段显示--

`PF_UI_Msg_Item`为底部消息栏信息列表表项预制体，是一个TMP。随机事件/掷骰子等简单操作不弹弹窗，直接在消息栏显示事件并在对应数值面板中修改数值。该消息栏有较大概率出bug，需要写完脚本后调整。

场景中小部分UI文件为了方便使用默认命名，但UI文件结构规范。

夜市管理相较于飞书文档的设计有一点改动，但主要功能相同。
