# 经济与资源系统模块交接说明 — 邵星岩 / 文智强

## 本次新增

为游戏添加完整的数值与资源管理系统，涵盖7个子系统：
1. **ResourceManager** — 资源管理器（资金/食材/体力/口碑）
2. **EconomyManager** — 经济结算系统（夜晚收入/贷款利息/事务封装）
3. **CustomerManager** — 客流分配系统
4. **EventManager** — 随机事件系统
5. **WeatherManager** — 天气系统
6. **InspectionManager** — 卫生审查系统
7. **MarketManager 集成** — 对接到夜市/摊位系统的资金检查/扣费

## 接口清单（供其他组员调用）

### ResourceManager 公开接口（资源操作）

```csharp
// ========== 资金 ==========
bool CheckMoney(int amount);        // 检查资金是否足够

void AddMoney(int amount);          // 加钱

// ========== 低端食材 ==========
bool CheckLowFood(int amount);
bool ConsumeLowFood(int amount);    // 消耗，不足返回 false
void AddLowFood(int amount);

// ========== 高端食材 ==========
bool CheckHighFood(int amount);
bool ConsumeHighFood(int amount);   // 消耗，不足返回 false
void AddHighFood(int amount);

// ========== 体力 ==========
bool CheckEnergy(int amount);
bool ConsumeEnergy(int amount);     // 消耗，不足返回 false
void RestoreEnergy(int amount);     // 恢复（不超过 maxEnergy）

// ========== 口碑 ==========
void AddReputation(int amount);
int GetCurrentReputation();

// ========== 绑定 ==========
void SetPlayerData(PlayerRuntimeData data);  // 运行时注入玩家数据
```

### EconomyManager 公开接口（经济结算）

```csharp
// ===== 夜晚收入结算 =====
void SettleAllMarketsNightIncome();
  // 遍历所有夜市 → 跳过停业夜市 → 按吸引力权重分配客流
  // → 客群偏好加权 → 消耗食材(不足收入打5折)
  // → 夜市4级口碑加成(1 + reputation×0.01) → AddMoney

  // 资金不足时自动增加贷款本金

bool BuildStallTransaction(string tileId, StallConfig stallConfig);
bool UpgradeStallTransaction(string tileId, string stallId, StallConfig stallConfig);
bool UpgradeMarketTransaction(string tileId);

// ===== 配置查找 =====
TileConfig FindTileConfig(string tileId);
StallConfig FindStallConfig(string stallId);

// ===== 依赖注入 =====
void SetResourceManager(ResourceManager manager);
void SetMarketManager(MarketManager manager);
void SetGameManager(GameManager manager);
void SetTileConfigs(List<TileConfig> configs);
void SetStallConfigs(List<StallConfig> configs);
```

### MarketManager 已集成资源检查/扣费的方法

| 方法 | 集成内容 |
|---|---|
| `CanCreateMarket(tileConfig)` | 检查 `CheckMoney(tileConfig.purchasePrice)`，不足返回 false + reason |
| `TryCreateMarket(tileConfig)` | 先 `SpendMoney(purchasePrice)`，失败返回 false |
| `CanUpgradeMarket(marketData)` | 检查 `CheckMoney(upgradeCost)`，不足返回 false + reason |
| `UpgradeMarket(tileId)` | 先 `SpendMoney(upgradeCost)`，失败返回 false |
| `CanBuildStall(marketData, stallConfig)` | 检查 `CheckMoney(stallConfig.buildCost)`，不足返回 false + reason |
| `CanUpgradeStall(marketData, stallData, stallConfig)` | 计算 `GetStallUpgradeCost` 后检查 `CheckMoney`，不足返回 false + reason |
| `UpgradeStall(tileId, stallId, stallConfig)` | 计算 `GetStallUpgradeCost` 后 `SpendMoney`，失败返回 false |

## 数值等级规范

详见 `Docs/Planning/数值等级规范.md`

定义了 **极少/少/中等/多/极多** 五个量级等级，覆盖15类数值：

| 概念 | 很少/很低 | 少/低 | 中等 | 多/高 | 很多/很高 |
|------|:--------:|:----:|:----:|:----:|:--------:|
| **资金(元)** | 1~500 | 500~2k | 2k~10k | 10k~50k | 50k+ |
| **低端食材** | 1~5 | 5~20 | 20~50 | 50~100 | 100+ |
| **高端食材** | 1~3 | 3~10 | 10~30 | 30~60 | 60+ |
| **客单价** | ≤5 | 5~15 | 15~40 | 40~80 | 80+ |
| **吸引力(摊位)** | — | 5~15 | 25~40 | 40~60 | 60+ |
| **吸引力(夜市)** | 1~30 | 30~80 | 80~150 | 150~300 | 300+ |
| **卫生值** | ≤50 | 50~70 | 70~85 | 85~95 | 95+ |
| **基础客流** | 1~20 | 20~50 | 50~100 | 100~200 | 200+ |
| **消费力倍率** | ≤0.3 | 0.3~0.7 | 0.7~1.3 | 1.3~1.8 | 1.8+ |
| **偏好倍率** | 0~0.3 | 0.3~0.7 | 0.7~1.3 | 1.3~1.8 | 1.8+ |
| **体力** | 1~20 | 20~40 | 40~60 | 60~80 | 80+ |
| **口碑** | 1~20 | 20~50 | 50~100 | 100~200 | 200+ |
| **概率** | 1%~5% | 5%~15% | 15%~30% | 30%~50% | 50%+ |
| **竞争强度** | 1~10 | 10~25 | 25~50 | 50~80 | 80+ |
| **地块价格** | — | — | 2k~4k | 4k~8k | 8k~15k |
| **夜市升级费** | — | — | 2,000 | 5,000 | 10,000 |

### 4. 资金操作快速测试（在任意脚本 Start 中运行）

```csharp
void Start()
{
    ResourceManager rm = FindObjectOfType<ResourceManager>();
    PlayerRuntimeData p = new PlayerRuntimeData();
    p.money = 5000;
    rm.SetPlayerData(p);

    Debug.Log(rm.CheckMoney(3000));     // True
    Debug.Log(rm.SpendMoney(2000));     // True, money=3000
    Debug.Log(rm.CheckMoney(4000));     // False
    Debug.Log(rm.SpendMoney(4000));     // False (未扣费)
    rm.AddMoney(7000);                  // money=10000
}
```

## 当前已知限制

1. 夜市总吸引力、总卫生值目前先按摊位基础值进行本地维护，后续需要 `DataManager` 提供完整摊位配置，并由客流、经济、检查、口碑等系统做最终修正。
2. `EconomyManager.ProcessLoanInterest` 的简化版本（只传 currentDay）为占位调用，正式调用请使用完整参数版本 `ProcessLoanInterest(currentDay, interestInterval, interestRate)`。
3. `StallManager` 中的 `CanBuildStall` 和 `CanUpgradeStall` 方法没有接入 ResourceManager 的资金检查（该模块定位为纯夜市/摊位规则检查辅助类），资金检查由 `MarketManager` 中的同名方法完成。
4. `MarketManager` 中仍有少量跨系统注释标记（CustomerManager / InspectionManager / DataManager 相关），等待对应组员接入。
5. README 中的启动场景路径 `Assets/_Project/CampusNightMarket/Scenes/S00_Bootstrap.unity` 当前不存在。
