# 数值等级规范 — HUST Night-Market

## 概述

本文档定义游戏中所有关键数值的"量级等级"，作为数值策划的统一参考标准。
所有数值配置应参考此规范，确保游戏内数值体系的一致性。

---

## 一、资金类（Money）

**单位：元**

| 等级 | 标签 | 玩家资金范围 | 举例说明 |
|------|------|-------------|---------|
| 0 | 无 | 0 | 破产 |
| 1 | 很少 | 1 ~ 500 | 连一个摊贩都建不起 |
| 2 | 少 | 500 ~ 2,000 | 刚好够建一个摊贩 |
| 3 | 中等 | 2,000 ~ 10,000 | 能建门店+少许升级 |
| 4 | 多 | 10,000 ~ 50,000 | 夜市升3级 + 多个摊位 |
| 5 | 很多 | 50,000+ | 接近胜利目标(10万) |

**资金数值模板（对应等级）**

| 项目 | 等级 | 数值 |
|------|:----:|:----:|
| **开局自有资金** | 中等 | 3,000 |
| **开局贷款** | 多 | 7,000 |
| **胜利目标** = (3,000 + 7,000) × 10 | 很多 | **100,000** |
| **夜市升级1→2** | 中等 | 2,000 |
| **夜市升级2→3** | 多 | 5,000 |
| **夜市升级3→4** | 多~很多 | 10,000 |
| **摊贩(StreetVendor)建设费** | 少 | 500 |
| **门店(Store)建设费** | 中等 | 2,000 |
| **连锁店(ChainStore)建设费** | 多 | 5,000 |
| **摊贩升级费** | 很少~少 | 300/次 |
| **门店升级费** | 少~中等 | 1,000/次 |
| **连锁店升级费** | 中等 | 2,500/次 |
| **普通地块购买价** | 中等 | 2,000 ~ 5,000 |
| **优质地块购买价** | 多 | 5,000 ~ 15,000 |

## 十一、口碑（Reputation）

| 等级 | 标签 | 口碑值 | 经济效果 |
|------|------|:-----:|:--------:|
| 0 | 无 | 0 | 无加成 |
| 1 | 低 | 1 ~ 20 | 收入 × 1.01 ~ 1.20 |
| 2 | 中低 | 20 ~ 50 | 收入 × 1.20 ~ 1.50 |
| 3 | 中等 | 50 ~ 100 | 收入 × 1.50 ~ 2.00 |
| 4 | 高 | 100 ~ 200 | 收入 × 2.00 ~ 3.00 |
| 5 | 很高 | 200+ | 收入 × 3.00+ |

**夜市4级口碑加成**（EconomyManager实现）：
总收入 × (1 + reputation × 0.01)，即每点口碑 = 1%收入加成
